# ExpChecker

Десктопное приложение для локального анализа Minecraft-клиента: проверка версий и модов, поиск чит-клиентов через Everything, анализ shellbags и загруженных в игру DLL. Чистый Win32 + GDI+, собственная отрисовка интерфейса — без стандартных контролов.

## Возможности

- **Проверка** — быстрая (~3.4 с) и полная (~7.6 с) локальная проверка с этапами и логом. Результаты сохраняются в «Отчёты».
- **Отчёты** — история проверок с оценкой, статусом и находками. Файлы, добавленные вручную, отображаются в карточке отчёта.
- **Майнкрафт** — анализ папки `.minecraft`: версии, моды, размер jar-файлов. Для известных версий (OptiFine/Fabric 1.21.4, 1.21.8, 1.21.11) размер jar сверяется с эталонным диапазоном — отклонение помечается как «подозрительный», нормальные файлы — «Не чит».
- **Утилиты** — встроенные **Everything** и **ShellBag**:
  - Everything запускается с автоматическим поиском `ext:jar;exe;lnk;pf` + список ~90 имён чит-клиентов. Результаты подтягиваются в приложение через Everything IPC (`WM_COPYDATA`). **ЛКМ** — открыть файл, **ПКМ** — добавить в отчёт.
  - ShellBag запускается с поисковым запросом по списку чит-клиентов.
- **Инжектор** — перечисление DLL, загруженных в процессы `javaw.exe`/`java.exe` (Toolhelp32). DLL вне системных/игровых папок помечаются как подозрительные.

## Использование

1. Запустите `ExpChecker.exe` — Windows запросит права администратора.
2. «Проверка» — выберите режим и запустите.
3. «Майнкрафт» — откройте вкладку для автоанализа версий и модов.
4. «Утилиты» — Everything/ShellBag запустятся автоматически со своим поиском.
5. «Инжектор» — откройте при запущенной игре для списка загруженных DLL.
